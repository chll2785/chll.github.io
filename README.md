# 조공부터 소장까지 — 웹사이트 버전 설정 안내

Claude 로그인 없이 누구나 주소로 접속해서 **아이디/비밀번호로 가입하고 어느 기기에서든 이어할 수 있는** 버전입니다.
계정과 세이브는 Firebase(구글의 무료 서버)에, 게임 파일은 GitHub Pages(무료 웹 호스팅)에 올립니다.

## 들어 있는 파일
| 파일 | 역할 |
|---|---|
| `index.html` | 게임 본체 |
| `firebase-config.js` | Firebase 연결 정보 (4단계에서 직접 채움) |
| `firestore.rules` | 세이브 보안 규칙 (3단계에서 붙여넣음) |

## 1단계. Firebase 프로젝트 만들기
1. https://console.firebase.google.com 에 구글 계정으로 접속합니다.
2. **프로젝트 추가** → 이름 입력(예: `jogong-game`) → Google 애널리틱스는 꺼도 됩니다 → 만들기.

## 2단계. 아이디/비밀번호 로그인 켜기
1. 왼쪽 메뉴 **빌드 → Authentication → 시작하기**.
2. **로그인 방법** 탭 → **이메일/비밀번호** → 첫 번째 스위치만 **사용 설정** → 저장.
   - 게임은 이메일 없이 아이디만 받습니다. 내부적으로 `아이디@jogong.game` 형태로 저장하므로 실제 이메일은 필요 없습니다.

## 3단계. 세이브 저장소(Firestore) 만들기
1. 왼쪽 메뉴 **빌드 → Firestore Database → 데이터베이스 만들기**.
2. 위치는 **asia-northeast3 (서울)** 을 고르고, **프로덕션 모드**로 시작합니다.
3. 만들어지면 **규칙** 탭을 열고, 내용을 전부 지운 뒤 `firestore.rules` 파일 내용을 붙여넣고 **게시**합니다.
   - 이 규칙은 "각자 자기 세이브만 읽고 쓸 수 있음"을 뜻합니다.

## 4단계. 웹 앱 등록하고 연결 정보 복사
1. 왼쪽 위 톱니바퀴 → **프로젝트 설정** → 아래쪽 **내 앱** → 웹 아이콘(`</>`) 클릭.
2. 앱 닉네임 입력(예: `jogong-web`) → Firebase 호스팅은 체크하지 않음 → **앱 등록**.
3. 화면에 나오는 `firebaseConfig = { apiKey: ..., authDomain: ..., ... }` 의 값들을 `firebase-config.js` 에 그대로 옮겨 적고 저장합니다.
   - 이 값은 비밀번호가 아니라 앱 주소 같은 정보라 공개해도 괜찮습니다. 보안은 3단계 규칙이 담당합니다.

## 5단계. GitHub Pages에 올리기
1. https://github.com 에 로그인 → 오른쪽 위 **+ → New repository** → 이름 입력(예: `jogong`) → **Public** → Create.
2. 저장소 화면에서 **Add file → Upload files** → `index.html`, `firebase-config.js` 를 끌어다 놓고 **Commit changes**.
3. 저장소 **Settings → Pages** → Source는 **Deploy from a branch**, Branch는 **main / (root)** → Save.
4. 1~2분 뒤 같은 화면 위쪽에 주소가 나옵니다: `https://<깃허브아이디>.github.io/<저장소이름>/`

## 6단계. 게임 주소를 Firebase에 허용하기
1. Firebase **Authentication → 설정 → 승인된 도메인** → **도메인 추가**.
2. `<깃허브아이디>.github.io` 를 입력하고 추가합니다. (`https://`와 저장소 이름은 빼고 입력)

## 7단계. 확인
- 게임 주소로 접속했을 때 로그인 칸 아래에 **초록 점 + "Claude 로그인 불필요"** 문구가 나오면 성공입니다.
- 회색 점에 "이 브라우저에 저장"이 나오면 `firebase-config.js` 값이 비었거나 잘못된 것입니다.
- 가입이나 로그인에서 오류가 나면 화면의 안내 문구가 몇 단계를 확인할지 알려줍니다.

## 알아둘 점
- **비밀번호 찾기는 안 됩니다.** 이메일 없이 가입하는 방식이라, 잊어버리면 새 아이디를 만들어야 합니다. 비밀번호는 6자 이상입니다.
- **무료 한도**: Firestore 무료 요금제는 하루 쓰기 2만 회 정도입니다. 세이브는 스테이지 클리어·스킬·강화 때마다 저장되므로 대략 하루 수십~백여 명이 즐기는 규모까지는 무료로 충분합니다.
- 게임을 업데이트할 때는 `index.html` 만 새 파일로 바꿔 올리면 됩니다. `firebase-config.js` 는 그대로 둡니다.
